# Library Management System

A simple console-based Library Management System developed in C++.

## Features
- View available books
- Issue books
- Return books
- Manage book quantity
- Menu-driven interface

## Technologies Used
- C++
- Object-Oriented Programming (OOP)

## How to Run

1. Compile the code:
   g++ library-management-system.cpp -o library

2. Run the program:
   ./library
